# Recall

AI 기반 용어 암기 프로그램

Recall은 강의자료와 교재 이미지에서 용어를 추출하고,
AI 채점과 반복 학습을 통해 효율적으로 암기할 수 있도록 도와주는 데스크톱 앱입니다.

## 다운로드

| 운영체제 | 다운로드 |
|---|---|
| 🍎 macOS (Apple Silicon) | [Mac용 다운로드](https://github.com/jjin5262/recall-releases/releases/latest) |
| 🪟 Windows (64-bit) | [Windows용 다운로드](https://github.com/jjin5262/recall-releases/releases/latest) |

현재 지원 버전: v0.1.0

## 주요 기능

- 강의자료 이미지에서 AI로 용어 추출
- ChatGPT(Codex) 및 Claude(Claude Code) 연결
- AI 기반 서술형 답안 채점
- 오답 재작성 및 반복 학습
- 용어집 로컬 저장

## 설치 안내

### macOS
1. DMG 파일을 다운로드합니다.
2. DMG를 열고 Recall을 응용 프로그램 폴더로 이동합니다.
3. Recall을 실행합니다.

### Windows
1. EXE 설치 파일을 다운로드합니다.
2. 설치 프로그램을 실행합니다.
3. Recall을 실행합니다.

## 안내

현재 Recall은 초기 테스트 버전입니다.
일부 환경에서는 보안 경고가 표시되거나 AI 연결 기능이 정상적으로 작동하지 않을 수 있습니다.

AI 기능을 사용하려면 지원되는 ChatGPT 또는 Claude 계정과 해당 CLI 도구의 설치 및 로그인이 필요합니다.# recall-releases
