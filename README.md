# Recall

Recall은 용어를 정리하고 암기하도록 돕는 데스크톱 프로그램입니다. 강의자료 이미지를 AI로 읽어 용어와 정의를 만들 수 있고, 용어를 직접 입력해 암기 테스트로 복습할 수도 있습니다.

## 다운로드

| 운영체제 | 설치 파일 |
| --- | --- |
| macOS Apple Silicon | [Mac용 다운로드 ⬇️](https://github.com/jjin5262/recall-releases/releases/download/v0.2.1/Recall_0.2.1_aarch64.dmg) |
| Windows 64비트 (x64) | [Windows용 다운로드 ⬇️](https://github.com/jjin5262/recall-releases/releases/download/v0.2.1/Recall_0.2.1_x64-setup.exe) |

현재 최신 버전: v0.2.1

macOS 파일은 Apple Silicon(M1, M2, M3, M4 등)용입니다. Intel Mac용 설치 파일은 제공하지 않습니다. Windows 파일은 64비트(x64)용입니다.

설치 파일은 이 저장소의 [Releases](https://github.com/jjin5262/recall-releases/releases)에 있습니다. 다른 사이트에서 받은 파일은 사용하지 마세요.

## 주요 기능

- 강의자료와 교재 이미지에서 AI로 용어와 정의 추출
- 추출된 용어와 정의를 직접 수정
- 용어집 만들기와 관리
- 서술형 암기 테스트
- 출제 방식, 출제 범위, 문제 순서 선택
- AI 채점, 또는 AI 없이 저장한 정답과 직접 비교
- 오답은 다시 작성하고 오답 복습으로 반복
- 용어집을 이 컴퓨터에 저장
- 앱 안에서 업데이트 확인 및 설치

## 설치 방법

### macOS

1. macOS Apple Silicon용 DMG 파일을 다운로드합니다.
2. 다운로드한 DMG 파일을 엽니다.
3. Recall.app을 응용 프로그램 폴더로 이동합니다.
4. Recall을 실행합니다.

보안 경고가 나타나지 않으면 추가 설정 없이 실행하면 됩니다.

#### macOS 보안 경고가 나타나는 경우

Recall은 현재 Apple Developer ID 서명과 공증이 완료되지 않은 초기 배포 버전입니다. 그래서 macOS에서 다음과 같은 경고가 나올 수 있습니다.

“Apple은 Recall에 악성 코드가 없음을 확인할 수 없습니다.”

이 경고는 Apple의 개발자 확인과 공증이 끝나지 않아 나타날 수 있습니다. 경고가 나왔다는 사실만으로 악성 코드가 있다는 뜻은 아닙니다. 이 페이지의 Releases에서 받은 파일인지 확인한 뒤, 설치를 계속하려면 다음 순서를 따르세요.

1. 경고 창에서 ‘완료’를 선택합니다.
2. Mac의 ‘시스템 설정’을 엽니다.
3. ‘개인정보 보호 및 보안’으로 이동합니다.
4. Recall 항목의 ‘그래도 열기’를 선택합니다.
5. Mac 암호 또는 Touch ID로 승인합니다.
6. Recall을 다시 실행합니다.

### Windows

1. Windows x64용 EXE 설치 파일을 다운로드합니다.
2. 설치 파일을 실행합니다.
3. 설치 과정을 완료합니다.
4. Recall을 실행합니다.

Windows Defender SmartScreen에서 경고가 나타날 수 있습니다. 앱의 디지털 서명이나 배포 평판이 아직 충분히 확인되지 않은 경우에도 이런 경고가 나옵니다. 경고만으로 악성 코드 여부를 판단할 수는 없습니다. 설치 파일이 이 저장소의 Releases에서 제공된 것인지 확인하고, 출처를 신뢰할 수 있을 때만 설치하세요.

## AI 연결 방법

AI 용어 추출과 AI 채점은 사용자가 설치한 CLI를 사용합니다. Recall이 AI 이용권을 제공하지는 않습니다. 이용 가능 여부와 한도는 각 서비스의 요금제와 정책을 따릅니다.

지원하는 도구는 둘 중 하나만 준비하면 됩니다.

| 도구 | 공식 설치 문서 |
| --- | --- |
| OpenAI Codex CLI | https://learn.chatgpt.com/docs/codex/cli |
| Anthropic Claude Code CLI | https://code.claude.com/docs/en/install |

1. Codex CLI 또는 Claude Code CLI를 설치합니다.
2. 해당 서비스 계정으로 로그인합니다. 그 계정에서 CLI를 사용할 수 있어야 합니다.
3. Recall을 실행합니다.
4. 화면 오른쪽 위의 **AI 연결**에서 사용할 도구를 선택합니다.
5. 이미지에서 용어를 추출하거나, 암기 테스트에서 **AI 채점 ON**을 사용합니다.

## 사용 방법

1. 첫 화면에서 **새 용어집 만들기**를 누릅니다.
2. 용어와 정의를 직접 입력하거나, **이미지 첨부**에서 강의자료 이미지를 넣습니다.
3. **선택 이미지에서 용어 추출**을 누릅니다. 추출 방식은 **원문 유지**와 **핵심 정리** 중에서 고릅니다. 이 단계는 AI 연결이 필요합니다.
4. 추출된 용어와 정의를 확인하고 수정합니다.
5. **용어집 저장**을 누릅니다.
6. 용어집 화면에서 **암기 테스트**를 엽니다.
7. **출제 방식**에서 `용어 → 정의` 또는 `정의 → 용어`를 고릅니다.
8. **출제 범위**에서 `전체 용어`, `번호 범위 지정`, `개별 용어 선택` 중 하나를 고르고, **문제 순서**를 정합니다.
9. **채점 방식**을 고릅니다. **AI 채점 OFF**는 입력한 답을 저장한 정답과 비교합니다. **AI 채점 ON**은 의미와 핵심 내용을 AI가 채점하며, 연결한 계정의 사용 한도를 쓸 수 있습니다.
10. **테스트 시작** 후 답을 쓰고 **채점하기**를 누릅니다.
11. 정답이면 다음 문제로 넘어갑니다. 오답이면 정답을 다시 작성하고 **재작성 완료**를 누릅니다.
12. 틀린 문제는 **오답 복습**으로 다시 나옵니다. 잘 모르겠으면 **모르겠어요**를 누를 수 있습니다.

## 데이터 저장 및 개인정보 안내

용어집은 이 컴퓨터에만 저장됩니다. 별도의 온라인 계정에 올리지 않습니다. 앱을 종료했다가 다시 실행해도 같은 파일을 읽으므로 용어집은 유지됩니다. 앱 업데이트도 프로그램만 바꾸고 이 저장 폴더는 바꾸지 않습니다.

| 운영체제 | 용어집 파일 |
| --- | --- |
| macOS | `~/Library/Application Support/com.recall.desktop/glossaries.json` |
| Windows | `%APPDATA%\com.recall.desktop\glossaries.json` |

같은 폴더의 `ai-provider.json`에는 선택한 AI 도구 이름만 저장됩니다. API 키, 로그인 토큰, 계정 암호는 Recall이 저장하지 않습니다. CLI 로그인 정보는 각 CLI가 자체적으로 보관합니다.

앱 안에 백업이나 복원 기능은 없습니다. 응용 프로그램이나 Windows 설치 프로그램을 지워도 위 폴더는 자동으로 지워지지 않습니다. 그 폴더나 `glossaries.json`을 직접 지우거나, 컴퓨터를 초기화하면 용어집은 사라지며 앱으로 되돌릴 수 없습니다.

AI 기능을 쓰면 처리에 필요한 내용이 선택한 외부 AI 서비스로 전달됩니다. 이미지에서 용어를 추출할 때는 첨부한 이미지가, AI 채점을 할 때는 문제와 저장한 정답, 작성한 답이 해당 CLI를 통해 전달됩니다. Recall은 이 내용을 모아 두는 자체 서버가 없습니다.

## 자동 업데이트

Recall은 실행 중에 새 버전을 확인할 수 있습니다. 화면의 **업데이트 확인**을 누르거나, 새 버전이 있으면 실행할 때 안내가 나타납니다. **지금 업데이트**를 누르면 설치 후 앱이 다시 실행됩니다.

업데이트 후에도 용어집 파일은 같은 위치에 남습니다. 앱 안에 백업 기능은 없으므로, 업데이트 전에 앱이 용어집을 따로 복사해 주지는 않습니다. 업데이트가 되지 않으면 이 페이지의 최신 설치 파일을 받아 직접 설치할 수 있습니다. 같은 컴퓨터에 다시 설치하면 기존 용어집 파일을 그대로 읽습니다.

## 자주 묻는 질문

### Recall은 무료인가요?

네. Recall 프로그램은 무료로 다운로드해 사용할 수 있습니다. AI 용어 추출과 AI 채점은 OpenAI Codex CLI 또는 Anthropic Claude Code CLI로 실행되므로, 그 서비스의 요금제와 이용 한도에 따라 비용이 들거나 사용이 제한될 수 있습니다. Recall은 AI 서비스의 유료 이용권을 제공하지 않습니다.

### ChatGPT 또는 Claude 계정이 필요한가요?

AI 기능을 쓰려면 지원되는 계정과 CLI가 필요합니다. Codex CLI와 Claude Code CLI 중 하나만 설치하고 로그인한 뒤, Recall의 **AI 연결**에서 그 도구를 선택하면 됩니다. 두 서비스를 모두 준비할 필요는 없습니다. 해당 계정에서 CLI를 사용할 수 있어야 합니다.

### AI 기능 없이도 사용할 수 있나요?

네. 용어집을 직접 만들고 수정한 뒤 암기 테스트를 할 수 있습니다. 채점 방식의 기본값은 **AI 채점 OFF**이며, 입력한 답을 저장한 정답과 직접 비교합니다. 이미지에서 용어를 추출하는 기능과 **AI 채점 ON**은 AI 연결이 있어야 사용할 수 있습니다.

### Mac 또는 Windows에서 보안 경고가 나타나는 이유는 무엇인가요?

Recall은 초기 배포 단계라, 운영체제가 요구하는 개발자 인증이나 앱 평판이 아직 충분하지 않을 수 있습니다. macOS에서는 Apple Developer ID 서명과 공증이 없어 Gatekeeper 경고가 나올 수 있습니다. Windows에서는 디지털 서명이나 SmartScreen 평판 때문에 경고가 나올 수 있습니다.

이 경고는 프로그램의 출처를 확인하라는 표시입니다. 경고가 있다는 사실만으로 악성 코드가 있다는 뜻은 아니고, 경고가 없다는 사실만으로 안전이 보장되지도 않습니다. 이 저장소의 Releases에서 받았는지 확인하고, 출처를 신뢰할 수 있을 때만 설치하세요. macOS에서 실행을 허용하는 순서는 위의 설치 방법을 따르면 됩니다.

### Windows에서도 사용할 수 있나요?

네. Windows 64비트(x64)용 EXE 설치 파일을 제공합니다. Windows ARM 등 다른 종류는 지원하지 않습니다.

### Intel Mac에서도 사용할 수 있나요?

아니요. 제공하는 macOS 설치 파일은 Apple Silicon용입니다. Intel Mac용 파일은 없으며, Intel Mac에서의 설치와 실행은 보장하지 않습니다.

### 용어집 데이터는 어디에 저장되나요?

이 컴퓨터의 폴더에 저장됩니다. 온라인 계정에 올릴 필요는 없습니다. 경로는 위의 “데이터 저장 및 개인정보 안내”와 같습니다. 앱을 끄거나 업데이트해도 그 파일은 유지됩니다. 백업과 복원 기능은 없습니다. 저장 폴더를 지우거나 컴퓨터를 초기화하면 용어집은 사라집니다.

### 업데이트는 어떻게 하나요?

앱의 **업데이트 확인**으로 새 버전을 설치할 수 있습니다. 그 기능이 동작하지 않으면 이 페이지에서 최신 설치 파일을 받아 설치하면 됩니다. 업데이트와 다시 설치 후에도 같은 컴퓨터의 용어집 파일은 유지됩니다. 별도의 백업 기능은 없습니다.

### AI 연결이 실패하면 어떻게 하나요?

1. Codex CLI 또는 Claude Code CLI가 설치되어 있는지 확인합니다.
2. 그 CLI에서 로그인이 끝났는지 확인합니다.
3. AI 서비스의 이용 한도와 계정 권한을 확인합니다.
4. 인터넷 연결을 확인합니다.
5. Recall의 **AI 연결**에서 선택한 도구가 맞는지 확인합니다.
6. 터미널에서 그 CLI가 실행되는지 확인합니다.
7. Recall을 완전히 종료한 뒤 다시 실행합니다.

그래도 해결되지 않으면 [Issues](https://github.com/jjin5262/recall-releases/issues)에 남겨 주세요. 운영체제, Recall 버전, 사용한 AI CLI, 오류 메시지를 함께 적어 주시면 원인을 보는 데 도움이 됩니다. API 키, 인증 토큰, 개인정보가 들어 있는 내용은 올리지 마세요.

## 오류 신고 및 문의

오류와 문의는 이 저장소의 [Issues](https://github.com/jjin5262/recall-releases/issues/new)에 남겨 주세요. 가능하면 다음을 포함해 주세요.

- 운영체제와 버전
- Recall 버전
- 오류가 난 기능
- 오류가 나기까지의 과정
- 오류 메시지 또는 스크린샷
- 사용한 AI CLI 종류(해당할 때)

API 키, 인증 토큰, 개인정보가 포함된 글과 화면은 공개하지 마세요.
